# Pomodoro Timer

A simple Pomodoro timer built with Python and Tkinter.

## About

This project is part of my journey learning Python and application development. I'm building the timer step by step to understand programming concepts, graphical user interfaces, and version control.

## Planned Features

- [ ] Start, pause, and reset the timer
- [ ] Customizable work and break durations
- [ ] A simple graphical interface using Tkinter
- [ ] Session tracking

## Technologies

- Python
- Tkinter
- Git and GitHub

## Current Status

Early development. The project currently contains the initial Python entry point, and features will be added incrementally as I learn.
